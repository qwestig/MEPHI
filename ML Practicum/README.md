# ML Practicum

Лабораторные работы по дисциплине «Практикум ML».

## Лабораторные работы

- [Лабораторная работа №1 — линейная регрессия](Labs/%231/sem_1_lineal_regression.ipynb)
- [Лабораторная работа №2 — методы линейной регрессии](Labs/%232/sem_2_linreg_methods.ipynb)

Работы хранятся в папках `Labs/#1`, `Labs/#2` и далее.

## Запуск лабораторной №1

Установите зависимости:

```bash
python -m pip install numpy pandas scipy scikit-learn matplotlib jupyterlab
```

Откройте папку `Labs/#1` в JupyterLab или VS Code, выберите ноутбук `sem_1_lineal_regression.ipynb` и выполните ячейки по порядку. Рабочая папка ядра должна быть `Labs/#1`; датасет находится рядом с ноутбуком.

В папке также сохранена таблица тестовых прогнозов `test_predictions_improved.csv`.
