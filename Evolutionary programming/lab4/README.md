# Лабораторная № 4 — эволюционная генерация входных данных

Вариант 13: автоматическая генерация тестовых данных, покрывающих ветви программы. Входные данные являются предметом задания; отдельной папки модульных проверок нет.

Сравниваются случайный поиск, ГА с редкостью посещения ветвей и направленный ГА с расстоянием до условий, подходным уровнем, выбором цели и памятью близких кандидатов. По 30 независимых запусков, ровно 6000 исполнений на запуск. В исследуемом модуле 22 условия и 44 исхода ветвей.

## Материалы

- `proposal.md` — заявка, подготовленная перед основной реализацией;
- `report.md` — постановка, архитектура, формулы, сравнение, ограничения и сценарий защиты;
- `data/target_program.py` — исследуемые функции;
- `configs/experiment.json` — параметры и калибровочная сетка;
- `results/runs.csv`, `summary.csv`, `trajectories.csv` — все 90 запусков;
- `results/branch_map.json` — карта условий и калибровочные свидетели достижимости;
- `results/branch_rates.csv` — повторяемость покрытия каждой ветви;
- `results/suites.json` — наборы входов всех запусков;
- `results/best_suite.json`, `best_suite.csv` — демонстрационный набор;
- `results/experiment_snapshot.json` — параметры, исходник и версия Python;
- `results/convergence.*`, `quality.*`, `branch_coverage.*` — PNG и SVG.

## Запуск

Python 3.10+, стандартная библиотека. Команды из папки дисциплины, содержащей `lab1`–`lab4` (на GitHub это `Evolutionary programming`):

```bash
python3 lab4/src/run_experiments.py
python3 lab4/src/build_report.py
python3 lab4/src/replay_suite.py
```

Последняя команда повторно исполняет сохранённые входы и выводит покрытие. Приложенный лучший набор имеет 25 входов и покрывает 44/44 ветви. В серии направленный метод достиг 100% только один раз из 30; среднее покрытие 94,17%. Полная статистика находится в отчёте.

Скрипты находят данные относительно своих файлов, поэтому рабочий каталог не влияет на пути по умолчанию. Повторный расчёт перезаписывает результаты; входы и покрытие детерминированы seed и версией Python, измеренное время может меняться.

```bash
python3 lab4/src/run_experiments.py --config lab4/configs/experiment.json --output lab4/results
python3 lab4/src/replay_suite.py --suite lab4/results/best_suite.json
```

Построители графиков и отчёта используют стандартную папку `results`. Текст стандартной постановки в отчёте относится к приложенной программе и параметрам; при их изменении текст нужно скорректировать.

## Архитектура и бюджет

`instrumentation.py` — AST-преобразование, карта ветвей, исполнение, расстояния и подходный уровень. `optimizer.py` — архив свидетелей, память близких кандидатов, вариация, два ГА и сокращение набора. `run_experiments.py` — общая калибровка достижимости, серии, статистика и повтор сохранённых входов. `replay_suite.py` — демонстрация выбранного набора.

В бюджет входят все поисковые исполнения, включая случайные пополнения. Калибровка сетки (46 875 исполнений), сокращение и итоговый повтор выполняются отдельно; калибровочные входы не используются как начальная популяция. Меньший набор при меньшем покрытии сам по себе не лучше.

Инструментатор предназначен для приложенного доверенного модуля с чистыми целочисленными функциями и одиночными сравнениями. Он не является песочницей для чужого Python-кода. Достижение 100% покрытия не гарантирует корректность результатов программы.

Сценарий демонстрации на 5–7 минут находится в разделе 9 отчёта: исходник, редкая ветвь, фитнес, серия запусков, повтор лучшего набора и ограничения.
