# Лабораторная работа №1 — генетический алгоритм для функции Саломона

Вариант 13. Минимизируется функция Саломона в пространстве размерности `d = 6` на области `[-100; 100]^6`. Глобальный минимум равен `0` и достигается в нулевом векторе.

## Метод

- вещественное кодирование: вектор из шести координат;
- турнирная селекция (турнир из 3 кандидатов);
- арифметический кроссовер;
- гауссовская мутация;
- ограничение координат диапазоном поиска;
- элитизм: лучшая особь переносится в следующее поколение.

## Запуск

Из папки `lab1`:

```bash
python3 src/run_experiments.py
```

Команда выполняет 20 запусков каждой конфигурации и случайного поиска. Результаты сохраняются в `results/`:

- `runs.csv` — результаты каждого запуска и найденные векторы;
- `summary.csv` — лучшая, средняя, медианная, худшая величины и стандартное отклонение;
- `trajectories.csv` — траектории сходимости.

Для графика выполните:

```bash
python3 src/plot_results.py
```

Будет создан `results/convergence.svg`. Скрипт использует только стандартную библиотеку Python.

## Конфигурация

Все параметры эксперимента находятся в `configs/experiment.json`: seed, число запусков, бюджет оценок, параметры популяции и двух сравниваемых конфигураций. Чтобы сравнение было честным, все методы получают одинаковый бюджет в 3000 вычислений функции.
