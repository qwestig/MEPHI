# Лабораторная работа №1: многомерная оптимизация функции Саломона

## Вариант и постановка

Вариант 13, размерность `d = 6`. Требуется минимизировать функцию Саломона на области `[-100; 100]^6`:

\[
f(x)=1-\cos(2\pi r)+0.1r,\qquad r=\sqrt{\sum_{i=1}^{6}x_i^2}.
\]

Глобальный минимум равен `f(0) = 0` и достигается в точке `x = (0, 0, 0, 0, 0, 0)`.

## Представление и алгоритм

Особь — вещественный вектор из шести координат. Популяция содержит 60 особей. Родители выбираются турнирной селекцией размера 3. Потомок создаётся арифметическим кроссовером, затем каждая координата с вероятностью 0.2 получает гауссовское возмущение. Выход за границы обрабатывается ограничением координаты интервалом `[-100; 100]`. Одна лучшая особь сохраняется элитизмом.

## Эксперимент

Использованы 20 независимых запусков с фиксированными seed. Бюджет каждого метода — 3000 вычислений целевой функции. Сравниваются две конфигурации, отличающиеся только масштабом мутации: `sigma = 10` и `sigma = 2`. Также проводится сравнение со случайным поиском при том же бюджете.

Результаты выполненной серии:

| Метод | Лучшее | Среднее | Медиана | Стандартное отклонение | Худшее |
| --- | ---: | ---: | ---: | ---: | ---: |
| Случайный поиск | 3.684107 | 4.751935 | 4.638626 | 0.700081 | 6.327909 |
| ГА, `sigma = 10` | 0.103428 | 0.215014 | 0.199967 | 0.055787 | 0.313570 |
| ГА, `sigma = 2` | 0.099873 | 0.165263 | 0.124418 | 0.095186 | 0.429803 |

График сходимости: `results/convergence.svg`. Линиями показаны средние лучшие значения по серии запусков, полупрозрачными полосами — диапазон от минимума до максимума.

## Вывод

Обе конфигурации генетического алгоритма значительно лучше случайного поиска при равном бюджете 3000 вычислений функции: среднее итоговое значение снизилось с `4.75` до `0.17–0.22`. Конфигурация с меньшим масштабом мутации (`sigma = 2`) показала лучшее среднее и медианное качество. Больший масштаб мутации (`sigma = 10`) дал более стабильный результат, но в среднем не так близко приблизился к глобальному минимуму. Это согласуется с характером функции Саломона: после нахождения перспективной области полезнее делать небольшие уточняющие изменения координат.
