# Лабораторная № 3 — многокритериальная конфигурация компьютера

Вариант 13, трек A. Собственный NSGA-II сравнивается с ГА со взвешенной суммой и случайным поиском по стоимости, мощности и производительности. По 20 независимых запусков, одинаковый бюджет 4000 оценок. В конечном каталоге 1920 сочетаний; точный фронт вычислен отдельно для оценки качества поиска.

## Материалы

- `report.md` — постановка, модель, алгоритмы, блок-схема, статистика и выводы;
- `data/catalogue.json` — синтетический каталог с seed 132603;
- `configs/experiment.json` — параметры;
- `results/runs.csv`, `summary.csv`, `trajectories.csv` — 60 запусков и их статистика;
- `results/fronts.json` — все найденные архивы по запускам;
- `results/reference_front.json` — точный фронт, границы нормирования и эталонный HV;
- `results/representatives.json` — четыре характерные конфигурации из лучшего по HV запуска NSGA-II;
- `results/experiment_snapshot.json` — данные фактического запуска и версия Python;
- `results/pareto.*`, `convergence.*`, `quality.*` — готовые PNG и SVG.

## Расчёт

Python 3.10+, стандартная библиотека. Команды из папки дисциплины, содержащей `lab1`, `lab2`, `lab3`, `lab4` (на GitHub это `Evolutionary programming`):

```bash
python3 lab3/src/problem.py
python3 lab3/src/run_experiments.py
python3 lab3/src/build_report.py
```

Первая команда восстанавливает приложенный каталог. Скрипты используют пути относительно своей папки, поэтому их можно запускать из любого рабочего каталога. Повторный расчёт перезаписывает результаты; данные и метрики воспроизводятся по seed, время зависит от компьютера. Сохранённые архивы и графики можно читать без запуска.

Другой файл параметров и папку результатов можно задать так:

```bash
python3 lab3/src/run_experiments.py --config lab3/configs/experiment.json --output lab3/results
```

Построитель отчёта и графиков использует стандартную папку `results`. Текст описания модели и стандартного плана в отчёте относится к приложенной конфигурации; при изменении модели его нужно скорректировать.

## Графики

Для повторного построения нужен Matplotlib. Можно использовать существующее окружение первой лабораторной:

```bash
lab1/.venv/bin/python lab3/src/plot_results.py
```

Или создать окружение для этой работы:

```bash
python3 -m venv lab3/.venv
lab3/.venv/bin/python -m pip install -r lab3/requirements.txt
lab3/.venv/bin/python lab3/src/plot_results.py
```

## Архитектура

`problem.py` — генерация каталога, декодирование, три цели и нормирование. `optimizer.py` — сортировка Парето, crowding distance, NSGA-II, скалярный ГА, случайный поиск, архив и точный гиперобъём. `run_experiments.py` — полный перебор для эталона и независимые серии. `plot_results.py` и `build_report.py` создают материалы по сохранённым данным.

На защите стоит объяснить доминирование, отличие HV от полноты фронта и выбор между дешёвой, экономичной, производительной и сбалансированной конфигурациями. Каталог и модель условные; работа не является аппаратным бенчмарком.
