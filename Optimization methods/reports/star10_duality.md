# Задание со звёздочкой 10
## Полная двойственная модель кредитования
## Вывод двойственной задачи
Прямая задача: max p^T x при A*x <= b, x >= 0. Матрица A включает три ресурсные строки и шесть строк единичной матрицы для спроса; b = (F,R,H,d1,...,d6). Для каждого из 9 ограничений введён неотрицательный множитель: uF,uR,uH для ресурсов и v1,...,v6 для спроса.

```math
min D = F*uF + R*uR + H*uH + sum_i d[i]*v[i]
uF + r[i]*uR + h[i]*uH + v[i] >= p[i]  (i=1,...,6)
uF,uR,uH,v[i] >= 0
```

Произведение множителя на соответствующий лимит имеет единицу млн руб. дохода за год. uF - доход на дополнительный млн руб. фондирования; uR - доход на дополнительную единицу риск-взвешенного объёма; uH - доход на дополнительный час; v[i] - доход на дополнительный млн руб. спроса данного филиала.

NumPy отдельно проверяет u >= 0 и A^T*u >= p, пересчитывает D = b^T*u и P = p^T*x. Проверяются u*(b-A*x) = 0 и x*(A^T*u-p) = 0 покомпонентно. Максимальные ошибки и разность целей находятся в пределах 1e-7. Значение прямой и двойственной целей совпадает: 17.2910068966 млн руб. в год.

## Почему это сертификат оптимальности
Для любого допустимого x и двойственно допустимого u верно p^T*x <= x^T*A^T*u <= b^T*u. Поэтому совпадение фактически найденных целей подтверждает глобальную оптимальность: улучшить прямое решение, не нарушив ограничения, невозможно. Численная проверка выполнена с оговорённым допуском и не заменяет точной рациональной арифметики для произвольной плохо обусловленной задачи.

## Предметная интерпретация
Риск-лимит имеет положительную цену, фондирование и часы - нулевую при наличии остатка. Положительные v1,v2,v3 означают, что расширение платёжеспособного спроса этих филиалов могло бы увеличить доход. Для B4 спрос не исчерпан, поэтому его множитель равен нулю. B5 и B6 не финансируются: стоимость потреблённого риска не меньше дохода.

Малое увеличение риск-лимита на 0.001 даёт прибавку 0.0002043103 млн руб. и совпадает с прогнозом. Большие изменения ресурсов в ЛР 1 меняют активный набор, поэтому исходная цена перестаёт быть точным прогнозом.
