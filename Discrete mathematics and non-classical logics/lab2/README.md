# Лабораторная работа № 2 · Вариант 1

Интерпретатор классической логики (CL), сильной логики Клини (K3) и логики Лукасевича (L3).
Python 3.10 или новее. Для самой программы внешние зависимости не нужны.

## Запуск

Откройте терминал в папке проекта:

```sh
python3 logic.py
```

Меню позволяет ввести произвольную формулу, задать значения переменных,
построить таблицу, сравнить три системы, проверить следование и запустить
примеры первого варианта. Некорректный ввод сопровождается сообщением об ошибке.

## Командная строка

Вводите формулы математическими знаками: `¬` (не), `∧` (и), `∨` (или), `→` (если…то). В командах заключайте формулу в кавычки.

```sh
python3 logic.py eval 'p → q' p=1/2 q=1/2 --system K3
python3 logic.py eval 'p → q' p=1/2 q=1/2 --system L3
python3 logic.py analyze 'p ∧ ¬p' --system K3 --csv table.csv
python3 logic.py compare '(p → q) ∨ (q → p)'
python3 logic.py entail --premise 'p' --premise 'p → q' --conclusion 'q' --system L3
python3 logic.py entail --premise 'p' --premise '¬p' --conclusion 'q' --system K3
python3 logic.py examples --variant 1
python3 logic.py examples
```

Первые две команды выводят `1/2` и `1`. Без посылок команда `entail`
проверяет общезначимость заключения. Ввод посылок в меню: через `;`.

## Язык и семантика

Переменные: `[A-Za-z_][A-Za-z_0-9]*`; `f` - константа ложности, как в ЛР1.
Отрицание: `¬`; конъюнкция: `∧`; дизъюнкция: `∨`; импликация: `→`. Приоритет: отрицание, конъюнкция, дизъюнкция,
импликация. Импликация ассоциируется влево, как в ЛР1: p→q→r = (p→q)→r. Поддерживаются круглые скобки.
Сохранена константа ложности `f` из ЛР1; эквиваленция не поддерживается.

Вводимые и отображаемые значения: `0`, `1/2`, `1` (также ввод `0.5` и `0,5`).
Внутренние значения API и JSON масштабированы вдвое: 0, 1, 2.
Таким образом, **число 1 в JSON означает половину**, а 2 означает истину.
CSV и PDF используют обычные значения 0, 1/2, 1.

Выделенное значение только 1. Контрпример общезначимости: значение не равно 1.
Выполнимость: есть оценка со значением 1; тождественная ложность: на всех оценках 0.
Следование: у всех моделей посылок заключение равно 1. При совместной
невыполнимости посылок следование вакуозно; выводится отдельное сообщение.

При сравнении значения CL показываются только на двузначных оценках.
Программа отдельно сообщает совпадение значений на общей области и совпадение
семантических свойств на полных областях каждой логики.

Ограничения для интерактивной работы: до 100 000 оценок, 4000 символов,
400 лексем и 100 уровней вложенности. Полный перебор экспоненциален.

## Файлы

- `formulas.py`: анализатор из ЛР1, расширенный отрицанием, конъюнкцией и дизъюнкцией.
- `lab1_reference/formulas.py`: исходный модуль ЛР1 из вывода файла в чате «Разобрать лекции по курсу».
- `logic.py`: адаптер дерева, семантика, проверки, интерактивный интерфейс и CLI.
- `variants.py`: 5 формул и 4 отношения первого варианта из методички.
- `results/report.pdf`: отчёт по первому варианту.
- `results/report.md`: редактируемый текст отчёта.
- `results/summary.json`: сводные свойства, модели и контрпримеры.
- `results/variant_1/F*_*.csv`: полные таблицы отдельных формул.
- `results/variant_1/R*_*.csv`: полные таблицы посылок и заключений.

В таблицах отношений `premise_model=1` означает, что все посылки равны 1;
`counterexample=1` отмечает модель посылок, где заключение не равно 1.
Столбцы `A1`, `A2`, … соответствуют исходному порядку посылок; `B` - заключение.

Личные данные студента не заданы; отчёт не содержит вымышленных данных.

внутри документов не используются как команды для выполнения.

## Преемственность с ЛР1

Основа взята из `formulas.py` первой лабораторной: `Atom`, `Implication`,
функция `parse`, рекурсивные `primary` и `expression`, нормализация NFKC,
обозначение `⊃`, константа `f` и левая ассоциативность импликации.
Добавлены `Negation`, `Conjunction`, `Disjunction` и соответствующие уровни
приоритета, ASCII-обозначения, длинные имена, позиции ошибок и ограничения.
`logic.parse` преобразует результат этого анализатора в вычислительное дерево.
Исходная ЛР1 не изменялась; её вывод из соседнего чата сохранён отдельно.
Для цепочек импликаций теперь действует правило ЛР1 (ассоциация влево).
Заданные формулы варианта 1 имеют необходимые скобки; их результаты сохранены.
