# Лабораторная работа № 1 — вариант 1

Консольный верификатор доказательств для системы исчисления высказываний. Нужен Python 3.10 или новее; внешние библиотеки не используются.

## Запуск

```sh
python3 main.py
```

Вводите формулы по одной строке. Поддерживается только знак импликации `⊃`, переменные — одиночные латинские буквы, `f` — постоянная ложь. Пробелы и скобки разрешены. Ввод `p ⊃ q ⊃ r` читается как `(p ⊃ q) ⊃ r`.

Команды внутри программы: `:axioms` показывает аксиомы, `:list` показывает принятые шаги, `:reset` начинает новый сеанс, `:help` выводит подсказку, `:quit` завершает программу.

## Проверки

```sh
python3 -m unittest discover -s tests -v
```

Тесты проверяют корректность формул, отклонение неправильного ввода, структуру формул, подстановку одной переменной, правила MP и β, а также сохранение принятых шагов. Полный пример доказательства печатает входные формулы и обоснования их принятия.

## Пример: доказать `p ⊃ p`

Вводите строки по порядку в запущенную программу:

```text
(s ⊃ (r ⊃ q)) ⊃ ((s ⊃ r) ⊃ (s ⊃ q))
(p ⊃ (r ⊃ q)) ⊃ ((p ⊃ r) ⊃ (p ⊃ q))
(p ⊃ (r ⊃ p)) ⊃ ((p ⊃ r) ⊃ (p ⊃ p))
p ⊃ (r ⊃ p)
p ⊃ r ⊃ (p ⊃ p)
(p ⊃ (q ⊃ p)) ⊃ (p ⊃ p)
p ⊃ p
:list
```

Ожидаемые основания шагов: β, β, β, β, MP, β, MP. Аксиомы K, S и E¬ доступны с начала сеанса; команда `:axioms` лишь показывает их.

## Файлы

- `formulas.py` — типы формул, синтаксический анализатор, поиск и применение одной подстановки.
- `verifier.py` — аксиомы, текущий список доказанных формул и проверка аксиом, MP и β.
- `main.py` — консольный ввод, команды сеанса и сообщения о результате.
- `tests/test_lab.py` — проверки парсера и верификатора.
